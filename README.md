# AndroidPlayerSDK (DEPRECATED)

> **This SDK is deprecated and no longer maintained.**
> Please migrate to the current Blue Billywig Native Player SDK.

## Migration

The replacement Android SDK is `com.bluebillywig.bbnativeplayersdk`, available via Gradle.
See [Blue Billywig Support](https://support.bluebillywig.com/) for the latest version and integration guide.

## About

This repository contained the legacy Blue Billywig Android Player SDK (Java, WebView-based). The last published version was v1.4.18 on Maven Central (`com.bluebillywig:BlueBillywigPlayerSDK`). Last updated in September 2021. No longer receiving updates, bug fixes, or security patches.
